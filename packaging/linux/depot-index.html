Le plus simple · The easy way

Téléchargez le paquet .deb sur la page des versions et ouvrez-le : il ajoute ce dépôt, et les versions suivantes arrivent avec les mises à jour du système.

Download the .deb package from the releases page and open it: it adds this repository, so new versions arrive with your system updates.

Avec apt · With apt

sudo wget -qO /usr/share/keyrings/alpirc-archive-keyring.gpg https://guiwald.github.io/alpirc/apt/alpirc-archive-keyring.gpg
printf 'Types: deb\nURIs: https://guiwald.github.io/alpirc/apt\nSuites: stable\nComponents: main\nArchitectures: amd64\nSigned-By: /usr/share/keyrings/alpirc-archive-keyring.gpg\n' | sudo tee /etc/apt/sources.list.d/alpirc.sources
sudo apt update
sudo apt install alpirc

Pour le retirer · To remove it: sudo apt remove alpirc

Le relais (serveur, facultatif) · The relay (server, optional)

Sur un serveur allumé en permanence, après les deux premières lignes ci-dessus · On an always-on server, after the first two lines above:

sudo apt update
sudo apt install alpirc-relay
sudo nano /etc/alpirc-relay/relay.toml
sudo systemctl enable --now alpirc-relay
