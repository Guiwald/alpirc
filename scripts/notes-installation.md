### Installer

| Appareil | Fichier |
|---|---|
| Mac (puce Apple ou Intel, macOS 11+) | `AlpIRC-X.Y.Z.dmg` : l'ouvrir, glisser AlpIRC dans Applications. La première fois : **Réglages Système › Confidentialité et sécurité › Ouvrir quand même** (appli non signée). |
| Android 8+ | `AlpIRC-X.Y.Z.apk` : l'ouvrir sur le téléphone, autoriser l'installation, puis les notifications. |
| Linux : Debian, Ubuntu, Mint | `alpirc_X.Y.Z_amd64.deb` : l'ouvrir, ou `sudo apt install ./alpirc_X.Y.Z_amd64.deb` ; les mises à jour arrivent ensuite avec celles du système. |
| Linux : les autres | `AlpIRC-X.Y.Z-linux-x86_64.tar.gz` : décompresser, puis lancer `./install.sh`. |
| Relais (serveur Linux, facultatif) | `alpirc-relay_X.Y.Z_amd64.deb` (quand il est fourni) : `sudo apt install ./alpirc-relay_X.Y.Z_amd64.deb`, puis régler `/etc/alpirc-relay/relay.toml`. |

Tout est expliqué pas à pas dans le [README](https://github.com/Guiwald/alpirc#installer).

### Install

| Device | File |
|---|---|
| Mac (Apple silicon or Intel, macOS 11+) | `AlpIRC-X.Y.Z.dmg`: open it, drag AlpIRC to Applications. The first time: **System Settings › Privacy & Security › Open Anyway** (the app isn't signed). |
| Android 8+ | `AlpIRC-X.Y.Z.apk`: open it on the phone, allow the installation, then notifications. |
| Linux: Debian, Ubuntu, Mint | `alpirc_X.Y.Z_amd64.deb`: open it, or `sudo apt install ./alpirc_X.Y.Z_amd64.deb`; updates then arrive with your system's. |
| Linux: others | `AlpIRC-X.Y.Z-linux-x86_64.tar.gz`: unpack it, then run `./install.sh`. |
| Relay (Linux server, optional) | `alpirc-relay_X.Y.Z_amd64.deb` (when provided): `sudo apt install ./alpirc-relay_X.Y.Z_amd64.deb`, then edit `/etc/alpirc-relay/relay.toml`. |

Step-by-step instructions are in the [README](https://github.com/Guiwald/alpirc#english).
